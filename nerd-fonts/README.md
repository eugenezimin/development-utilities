# Nerd Fonts

A collection of patched/custom monospace fonts for use in terminals, editors, and IDEs, with extended glyph support (powerline symbols, devicons, etc.) for prompt themes like Powerlevel10k.

## Fonts included

| Font | Notes |
|---|---|
| [Anka:Coder](./Anka%3ACoder/) | Coding-focused monospace font. |
| [Anka:Coder Condensed](./Anka%3ACoder%20Condensed/) | Condensed variant of Anka:Coder. |
| [Atlassian Sans](./Atlassian%20Sans/) | Atlassian's Sans typeface. |
| [AudioLink Console](./AudioLink%20Console/) | Console/terminal weight of AudioLink. |
| [AudioLink Mono](./AudioLink%20Mono/) | Monospace weight of AudioLink. |
| [Charlie Display](./Charlie%20Display/) | Display weight of Charlie. |
| [Charlie Text](./Charlie%20Text/) | Text weight of Charlie. |
| [Google Mono Sans Nerd](./Google%20Mono%20Sans%20Nerd/) | Google Sans Mono patched with Nerd Font glyphs. See its own [README](./Google%20Mono%20Sans%20Nerd/README.md). |

## Installation (macOS)

1. Open each `.ttf` file and click **Install Font**, or select all files in Finder, right-click, and choose **Install**.
2. Restart your terminal/editor and select the font in its preferences (e.g. [iterm2-config](../iterm2-config/) or [vscode-configuration-dark](../vscode-configuration-dark/)).
