# macOS Icons

An extended set of macOS 26 (Tahoe) style icons as 1024x1024 PNG images, for use with **Finder > Get Info > drag image onto icon well**, or any tool that lets you assign a custom app/folder icon.

## Contents

All icons live under [`macOS 26/`](./macOS%2026/):

| Folder | Contents |
|---|---|
| [Icons-APPS-Apple-1](./macOS%2026/Icons-APPS-Apple-1/) | Apple's own apps (Finder, Calculator, Calendar, Console, Dictaphone, etc.) |
| [Icons-APPS-Apple-2](./macOS%2026/Icons-APPS-Apple-2/) | Additional Apple apps. |
| [Icons-APPS-Other-1](./macOS%2026/Icons-APPS-Other-1/) | Third-party / other application icons. |
| [Icons-APPS-Other-2](./macOS%2026/Icons-APPS-Other-2/) | More third-party / other application icons. |
| [macOS-Folders](./macOS%2026/macOS-Folders/) | Standard system folder icons (Applications, Desktop, Documents, Downloads, Home, Library, Movies, Music, Pictures, Public, Users, Utilities, etc.). |
| [Other-Folders](./macOS%2026/Other-Folders/) | Additional custom folder icons. |

## Usage

1. Open the PNG for the icon you want in Preview and copy it (`Cmd+A`, `Cmd+C`), or select the file in Finder and `Cmd+C`.
2. Select the target app/folder in Finder, open **Get Info** (`Cmd+I`).
3. Click the small icon in the top-left of the Get Info window, then paste (`Cmd+V`).
## System-Wide Color Tint (for all icons)

1. Go to **System Settings > Appearance** (or Control Center, depending on the version/setting).
2. Look for "Accent Color" or "Tint" settings to apply a color to many default icons, including folders, system-wide.
