# Draw.io Custom Configuration

This is a custom configuration for the Draw.io desktop editor. It sets default styles for all vertices (geometric figures) and all edges (connectors for those vertices).

## Requirements

- [Draw.io Desktop](https://github.com/jgraph/drawio-desktop/releases)

## Installation

1. Launch the Draw.io Desktop application.
2. Open the **Extras -> Configuration...** menu.
3. Copy the contents of [custom-draw-io-config.json](./custom-draw-io-config.json) and paste it into the dialog.
4. Click **Apply**, then restart Draw.io Desktop — configuration is only loaded at startup.

All changes will be visible on the next application start.
